# Smart-Watering-System-with-Wemos-D1-R1-and-Blynk
IoT-based smart watering system using **Wemos D1 R1 (ESP8266)**, **DHT11**, and **YL-69 soil moisture sensor** to monitor plant conditions and control a DC water pump through **Blynk**. Supports automatic/manual watering, Wi-Fi connectivity, remote monitoring, and **OTA firmware updates**.

## 📌 Project Overview

This project demonstrates the development and integration of an IoT-based smart watering system, combining sensor monitoring, embedded control, Wi-Fi connectivity, remote monitoring, and actuator control.

### System Flow

**DHT11 + YL-69 → Wemos D1 R1 → Wi-Fi → Blynk → Relay → DC Pump**

The project was developed as a **team project** to strengthen practical skills in:

- Embedded Systems
- IoT System Integration
- Sensor Integration
- Microcontroller Programming
- Wi-Fi Connectivity
- Blynk IoT Platform
- Automatic Control
- Remote Device Control
- OTA Firmware Updates
- Hardware Integration

## 🎯 Project Objective

The objectives of this project are:

- Collect temperature and humidity data using a DHT11 sensor.
- Measure soil moisture using a YL-69 sensor.
- Process sensor data using a Wemos D1 R1.
- Connect the microcontroller to a Wi-Fi network.
- Monitor sensor data through the Blynk dashboard.
- Implement automatic watering based primarily on soil moisture conditions.
- Provide manual pump control through Blynk.
- Control the DC water pump using a relay.
- Implement OTA firmware updates for remote firmware deployment.
- Integrate the complete sensing, control, and monitoring system.
