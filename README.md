# Smart-Watering-System-with-Wemos-D1-R1-and-Blynk
IoT-based smart watering system using Wemos D1 R1 (ESP8266), DHT11, and YL-69 to monitor plant conditions and control a DC water pump through Blynk. Supports automatic/manual watering, Wi-Fi connectivity, remote monitoring, and OTA firmware updates.
